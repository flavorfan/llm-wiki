# Claude + Karpathy's Second Brain Tutorial (YouTube)

## Key Points

- **Video context**: YouTube tutorial by Nick B Zark demonstrating how to build a second brain using Claude Code and Obsidian based on Karpathy's April 2nd tweet.
- **Practical implementation**: End-to-end walkthrough of building second brain system in under 20 minutes using a Claude skill.
- **Second brain definition**: System to organize data to make yourself more effective - personal needs, business practices, content creation.
- **Karpathy's influence**: Tweet went "mega viral" - Karpathy is founding researcher at OpenAI and top influential AI figure.
- **Two key tweets**: Original (April 2nd) on building LLM knowledge base step-by-step, follow-up on "idea file" concept (intentionally vague framework).
- **Claude skill built**: Full end-to-end workflow as skill, using Vercel's framework, works with multiple AI harnesses (Claude Code, Codex, Gemini CLI, Open Code, Pi).
- **Skill features**: Setup wizard for new vault, ingest sources into wiki, query against wiki, lint (health check) for pruning and finding connections.
- **Tools used**: Obsidian (mind graph), Obsidian Web Clipper (Chrome extension for scraping), summarize (YouTube transcript extraction by Peter/Open Claw creator), qmd (optional search).
- **Three-tier structure**: raw/ (brain dump), wiki/ (organized by AI), outputs/ (queries and reports).
- **Graph view**: Visual representation of interconnections between wiki pages, shows relationships and identifies orphans.
- **Workflow**: Drop content into raw/ → run "second brain ingest" → AI analyzes and builds wiki graph → query anytime → lint periodically.
- **Loop capability**: Can automate ingestion on intervals (e.g., every few hours) using Claude Code's loop feature.
- **Scaling strategy**: Personal and business vaults separate, can sync across devices with Obsidian paid tier, graduate to RAG for larger scale.
- **Business use cases**: Meeting transcripts, Zoom calls, team collaboration, content strategy - compounds significantly over time.
- **Compounding value**: "Day zero it's kind of useful, but day 30, 60, 90 becomes hugely valuable company asset that nobody else has."
- **Mobile integration**: Can record notes on mobile, sync to raw/, auto-indexed by loop on desktop.
- **Market opportunity**: "Second brain as a service" predicted to explode - $2-5K setup + few hundred/month retainer for businesses.
