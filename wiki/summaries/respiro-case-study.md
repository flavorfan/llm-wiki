## Key Points

- **Builder profile**: Kostiantyn Vlasenko, project manager at Mythical Games with 10 years experience, zero coding experience before February 2026
- **Timeline**: 72 hours for hackathon prototype, 6 weeks to App Store-ready production app
- **Problem solved**: Existing stress management apps notify at scheduled times; Respiro detects stress signals in real-time and intervenes immediately
- **Tech stack**: Initially React Native, pivoted to Swift (rewrote in hours with Claude Code). 15+ specialized subagents for TCA architect, Swift developer, Metal specialist, code reviewer
- **Management approach**: "I have experience managing real people. This was the same thing, only managing agents inside my IDE"
- **Vision capabilities**: Used Claude's screenshot analysis as "most under-appreciated feature" to navigate unfamiliar UIs (Apple Developer Program, Meta API token creation)
- **Third-party integrations**: Sentry logging, Amplitude analytics, App Store submission - all configured via Claude with 99% success rate on first try
- **Marketing with Claude**: Blog posts, TikToks, analytics funnels, growth strategy (reaching out to psychologists/practitioners)
- **Day job impact**: Now ships features directly at Mythical Games, shared Claude workflow with engineering team with positive reception
- **Challenges**: Some engineers struggle switching mindset from controlling every line of code
- **Active development**: Building voice-guided practices, motion exercises from Claude-generated roadmap, logging 7-8 hours after work day
