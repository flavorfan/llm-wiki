## Overview

DBeaver Community is an open-source universal database management tool with graphical interface supporting multiple database systems (PostgreSQL, MySQL, SQLite, Oracle, etc.). Provides lighter-weight alternative to pgAdmin with broader database support. Java-based desktop application.

## Characteristics

- **Universal support**: Works with PostgreSQL, MySQL, SQLite, Oracle, SQL Server, MongoDB, and many more
- **Open source**: Free Community edition (commercial Pro/Enterprise versions available)
- **Lightweight**: Less resource-intensive than pgAdmin Electron app
- **Desktop application**: Java-based (requires JRE)
- **Rich features**: SQL editor, ER diagrams, data editor, import/export, query builder
- **Driver auto-download**: Automatically downloads JDBC drivers on first connection
- **Cross-platform**: Windows, Mac, Linux support

## Common Strategies

- Single tool for developers working with multiple database types
- Lightweight alternative to pgAdmin for PostgreSQL administration
- Data migration and comparison across different database systems
- Visual schema design and ER diagram generation
