# VS Code

## Overview

Visual Studio Code (VS Code) is a popular integrated development environment (IDE) developed by Microsoft. Used as a host environment for implementing [[concepts/auto-research]] workflows and running AI coding agents.

## Characteristics

**Environment type:**
- Free, open-source IDE
- Industry-standard code editor
- Supports extensive extension ecosystem
- Cross-platform (Windows, Mac, Linux)

**AI agent integration:**
- Can run [[entities/claude-code]] within the editor
- Supports autonomous coding loops
- Compatible with AutoResearch workflows
- Alternative to [[entities/cursor]]

**Usage in AutoResearch:**
- Host environment for AI agents
- Provides interface for code modification
- Enables repository management (git integration)
- Mentioned as standard option alongside Cursor
