# Cursor

## Overview

Cursor is an AI-powered integrated development environment (IDE) that supports AI coding agents. Mentioned as an alternative to VS Code for implementing [[concepts/auto-research]] workflows.

## Characteristics

**Environment type:**
- IDE (Integrated Development Environment)
- AI-native editor
- Supports AI coding agents
- Alternative to traditional editors like VS Code

**AI agent integration:**
- Can run [[entities/claude-code]] within the IDE
- Supports autonomous coding loops
- Enables "bypass permissions" mode for continuous operation
- Compatible with AutoResearch workflows

**Usage in AutoResearch:**
- Host environment for running experiment loops
- Provides interface for AI agents to modify code
- Enables long-running autonomous processes
- Used in tutorial demonstrations alongside VS Code

## Common Strategies

**AutoResearch setup:**
- Clone repositories within Cursor
- Launch AI agents (Claude Code, Codex)
- Set agents to bypass/Yolo mode for autonomous operation
- Monitor agent progress through IDE interface
