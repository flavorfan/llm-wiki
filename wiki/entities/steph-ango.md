## Overview

Steph Ango (GitHub: kepano) is the CEO of [[entities/obsidian]] and the creator of the official [[concepts/agent-skills]] repository for AI agent integration with Obsidian.

## Key Contributions

**Leadership**: 
- Current CEO of Obsidian
- Part of founding team with co-founders Erica Xu and Shida Li
- Advocates for local-first, privacy-respecting software design

**Open Source Work**:
- Maintains `kepano/obsidian-skills` repository
- Created essential Skills for AI agent integration:
  - [[concepts/obsidian-cli]] Skill wrapper
  - [[concepts/defuddle]] web scraping tool
  - obsidian-bases (database views)
  - obsidian-markdown (Obsidian-flavored Markdown)
  - json-canvas (whiteboard creation)

**Philosophy**: 
- Strong stance on data privacy and local-first architecture
- Official policy: Obsidian will never force cloud AI integration
- CLI as "open external interface" - users choose which AI frameworks to connect
- Empowers users to use local LLMs and NAS for complete data sovereignty

## Design Approach

- **Privacy-First**: No mandatory cloud services, no built-in AI that phones home
- **Extensibility**: Open CLI interface for community and third-party AI integration
- **User Control**: Users decide which AI tools to trust with their data
